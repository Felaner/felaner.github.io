# Broken Ranks Fandom Wiki

Неофициальная фанатская вики по MMORPG Broken Ranks на русском языке. Не связана с Whitemoon Games и Fandom, Inc.

Сайт: https://felaner.github.io/ · связь: Telegram [@felaner](https://t.me/felaner)

## Что есть

- экипировка, питомцы, противники, предметы, НПС, навыки, статьи и интерактивные карты;
- поиск по всей вики (горячая клавиша `/`), фильтры по уровню, редкости, классу и типу атаки;
- карточки записей со связями: «Падает с», «Используется в», «Входит в комплект» и т. п.;
- переодевалка (`#/build`): слоты, характеристики, сопротивления, комплекты, планировщик навыков, сборка в ссылке;
- избранное, заметки, сравнение, светлая и тёмная темы;
- статические страницы `e/<id>.html` и `sitemap.xml` для поисковиков.

## Просмотр

Открой `index.html` в браузере — сервер не нужен.

## Сборка

```bash
pip install -r scraper/requirements.txt
python scraper/build.py
```

`build.py` собирает `data/<раздел>.js`, статические страницы `e/`, `sitemap.xml` и `robots.txt`.
Подробности — в `КОНСПЕКТ.md`.
